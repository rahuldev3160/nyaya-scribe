# BUG-032 — Essay "High Prob" filter cannot be deselected

**Status:** FIXED | **Severity:** MEDIUM | **Session:** S47 | **Category:** navigation

## Symptom
On `/upsc/essay`, clicking "High Prob" filters to `is_high_probability=1`. There is no way to click it again to turn the filter back off — every rendering of the link always appends `&hot=1`.

## Root Cause
`essay_landing.html`'s "High Prob" link was a one-way toggle: `href="...&hot=1"` unconditionally, regardless of `filters.hot`. Unlike the adjacent "Section A/B" filters (which have a companion "All Sections" link to clear them), High Prob had no clear/off path.

Compounded by a real data gap: none of the 16 seeded PYQ essay questions (`content_type='pyq'`) have `is_high_probability=1` — only some `practice` rows do. So combining the Solved-PYQ tab with High Prob always returns zero results, which is what made the stuck-filter bug visible/painful.

## Fix
`essay_landing.html` — the High Prob link now conditionally omits `hot=1` when already active (toggle behavior matching Section A/B), and shows a "✕" affordance when active.

## File
`web/templates/essay_landing.html` (line ~53)

## Related gap (not fixed here)
No PYQ essay question is currently flagged `is_high_probability=1`. If "high probability PYQs" is a real product feature, someone needs to review/flag the PYQ set, not just the practice set.
