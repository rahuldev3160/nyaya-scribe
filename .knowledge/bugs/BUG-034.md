# BUG-034 — hero-strip / rec-card / stat-pills had zero CSS (dashboard looked like unstyled text)

**Status:** FIXED | **Severity:** LOW | **Session:** S47 | **Category:** ui

## Symptom
Eco Optional dashboard (`/upsc`), below "Browse Model Answers": the recommended-question block and "Readiness / UPSC Eco Optional / Today" row rendered as plain unstyled inline text with no card/box/color — looked broken/unfinished next to the rest of the styled dashboard.

## Root Cause
`upsc_dashboard.html` uses `.hero-strip`, `.rec-card`, `.rec-label`, `.rec-text`, `.stat-pills` classes that were never defined in `web/static/style.css` — they rendered with zero styling. Additionally the "Write Now →" link used `class="btn-primary"` alone (missing the base `.btn` class), so it got color overrides but none of `.btn`'s box/padding/border rules — rendered as a bare colored text link, not a button.

## Fix
- Added `.hero-strip`, `.rec-card`, `.rec-label`, `.rec-text`, `.stat-pills` rules to `style.css`, matching the existing gem-card/chip color system (`#8AB4F8` accent, `#2C2C2E` pill background), with a mobile stack breakpoint at 600px.
- Fixed "Write Now →" to `class="btn btn-primary btn-sm"`.
- Also restructured the dashboard into `.dash-2col`: left column = Browse Model Answers button + hero strip, right column = Paper I/II tabs — better use of horizontal space on wide screens (per Rahul's request), and reuses the app's existing 600px collapse-to-1-col rule so mobile is unaffected.

## Files
`web/static/style.css`, `web/templates/upsc_dashboard.html`
